# 丸酱媒体嗅探助手隐私政策

生效日期：2026-07-31  
联系渠道：[GitHub Issues](https://github.com/mercury321/maru-media-sniffer/issues)

丸酱媒体嗅探助手（Maru Media Sniffer）用于识别用户当前正在浏览页面中已经发出的公开媒体请求，并在用户主动点击后保存相应媒体文件。本扩展不提供 DRM 绕过、登录凭据导出、付费或访问控制绕过功能。

## 处理的信息

扩展仅在本机处理当前标签页的页面地址、页面标题、作者/封面等公开页面元数据、媒体地址及媒体响应类型或大小等必要信息。用户的文件名前缀和保存位置偏好通过 Chrome 存储保存。

## 使用与保存方式

上述信息仅用于当前页面的媒体发现、归组、命名和用户主动发起的下载。页面媒体记录按标签页保存在浏览器会话中，用户可在扩展内清空；浏览器关闭后会话记录会消失。HLS 下载可能使用浏览器本地临时存储，并在下载完成或失败时尽力清除。

## 不收集、不出售、不上传

本扩展没有开发者服务器、没有分析统计、没有广告 SDK，不会向开发者或任何第三方上传、出售或共享页面内容、媒体地址、下载记录、账号密码、Cookie 或身份信息。用户主动下载时，浏览器会直接与用户正在访问的网站及其媒体 CDN 通信。

## 权限说明

- `host_permissions` 与 `webRequest`：识别用户当前页面已经请求的媒体资源。
- `downloads`：在用户点击后保存文件。
- `storage`：保存本地设置和会话记录。
- `webNavigation`：在页面切换后清理旧记录。
- `declarativeNetRequestWithHostAccess`：让用户主动下载的公开媒体请求携带来源页信息。
- `offscreen`：本地处理临时媒体文件。
- `scripting`：扩展更新或重新加载后，在用户主动扫描时将嗅探脚本重新注入当前网页。

## 用户选择

你可以在扩展内清空当前页面媒体记录、在设置页修改本地偏好，或随时卸载扩展以删除扩展本地数据。

## Chrome Web Store User Data Policy

本扩展对网页资源和浏览活动数据的使用仅限于上述、用户可见的媒体发现与下载功能；不将这些数据用于广告、画像、出售或任何与该单一目的无关的用途。
