## 中文

**名称**：丸酱媒体嗅探助手

**简短说明**：识别当前网页已加载的公开媒体资源，按标题和来源整理后由你一键保存。

**详细说明**：

丸酱媒体嗅探助手让网页媒体资源更容易辨认。打开正在播放视频的页面后，扩展会将已经加载的公开媒体请求按页面标题、作者、封面和来源页面整理为清晰条目。

- 自动识别 MP4、WebM 和 HLS 播放列表
- 不将 HLS 分片平铺成大量无意义文件
- 支持按页面标题生成易读文件名
- 微博视频会合并多个清晰度地址并优先选择最高可识别画质
- B 站可识别完整 MP4 或音视频分离流
- 工具栏数字角标提示当前页面可用媒体数量
- 页面信息和下载准备均在本机完成

本扩展只处理浏览器已经请求到、且你有权保存的公开内容。它不绕过 DRM、登录、付费或访问控制，不导出 Cookie、密码或其他账号凭据。

## English

**Name**: Maru Media Sniffer

**Short description**: Detect publicly loaded media on the current page, organize it with readable context, and let you save content you are authorized to keep.

**Detailed description**:

Maru Media Sniffer helps you identify media already loaded by the page you are viewing. It organizes public media requests using page titles, creators, cover images, and source pages, so you can tell which item is relevant before saving it.

- Detect direct MP4/WebM media and HLS playlists
- Keep HLS segments grouped instead of listing hundreds of fragments
- Create readable filenames from page context
- Merge Weibo quality variants and prefer the highest recognizable quality
- Show a toolbar badge for media found on the current page
- Process page context and download preparation locally in your browser

The extension only handles public content already requested by the browser that you are authorized to save. It does not bypass DRM, logins, payment gates, or access controls, and it never exports cookies, passwords, or other credentials.
