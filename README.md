# 丸酱媒体嗅探助手

**Maru Media Sniffer** 是一款面向 Chrome 的媒体资源识别与下载扩展。

它会监听页面中的公开媒体请求，并结合网页标题、作者、封面、分集信息和来源页面，把难以辨认的媒体地址整理成更直观的视频条目。工具栏图标使用红色“丸”字；“丸酱”是作者对女儿的昵称。

> 当前项目处于测试阶段。不同网站会随时调整播放器、鉴权方式和媒体地址，部分页面可能只能识别，暂时无法直接下载。

## 主要功能

- 识别常见的 MP4、WebM、M4A、M4S、MP3 和 HLS（M3U8）等媒体请求。
- 按当前标签页归组资源，避免不同网页之间的记录混在一起。
- 读取视频标题、作者或频道、封面、分集标题及来源页面。
- 自动去除重复请求，减少分片、预加载资源和不同清晰度造成的重复条目。
- 工具栏角标显示当前页面识别到的可用媒体数量。
- 页面只有一条媒体时，直接在顶部显示下载按钮；存在多条媒体时，再展示资源列表。
- 支持普通直链下载、HLS 分片下载，以及部分网站的 DASH 视频流和音频流下载。
- 提供手动重新扫描和清除当前页面记录功能。
- 扩展更新或重新加载后，重新扫描会自动恢复当前网页的嗅探脚本。
- 所有识别数据都保存在本地，不接入开发者服务器、广告或统计服务。

## 支持范围

| 网站或格式 | 当前支持情况 | 下载结果与说明 |
| --- | --- | --- |
| 通用 MP4 / WebM | 支持 | 直接保存浏览器公开请求中的媒体文件 |
| HLS / M3U8 | 支持 | 自动选择可用的高码率清晰度并下载分片；根据流格式保存为 `.ts` 或 `.mp4` |
| B 站 | 支持识别与归组 | 优先使用可用的完整 MP4；DASH 页面可能分别下载视频 `.m4s` 和音频 `.m4s` |
| 微博 | 针对性适配 | 合并同一视频的多个清晰度地址，并优先选择较高清晰度 |
| X（Twitter） | 针对性适配 | 识别帖子中的 HLS 视频，过滤一部分直播和预加载请求；网站更新后可能暂时失效 |
| YouTube | 实验性支持 | 优先下载带音频的完整视频；高画质常采用 DASH，可能需要分别下载视频和音频 |

插件只处理浏览器已经访问到的公开媒体资源，不提供 DRM 解密、登录凭据导出、付费内容破解或访问控制绕过。

## 安装

### 方法一：安装 GitHub Release 版本

1. 在仓库的 **Releases** 页面下载最新的 ZIP 安装包。
2. 将 ZIP 完整解压到一个固定目录，不要直接打开或删除解压后的文件夹。
3. 在 Chrome 地址栏输入 `chrome://extensions/`。
4. 打开右上角的“开发者模式”。
5. 点击“加载已解压的扩展程序”。
6. 选择解压后、能够直接看到 `manifest.json` 的目录。
7. 将“丸酱媒体嗅探助手”固定到浏览器工具栏。

Chrome 不能直接安装本项目生成的 ZIP 文件。ZIP 用于上传 Chrome Web Store 或分发，手动安装时必须先解压。

### 方法二：从源码构建

需要先安装 [Node.js](https://nodejs.org/) 20 或更高版本。

```bash
npm install
npm run check
npm run build
```

构建完成后，在 `chrome://extensions/` 中选择项目里的 `dist` 目录。

## 使用方法

1. 打开包含视频的网页。
2. 播放视频几秒，让网页真正发起媒体请求。
3. 工具栏“丸”字图标出现数字后，点击打开插件。
4. 检查标题、作者、封面和媒体类型是否对应当前视频。
5. 点击“下载当前视频”或资源条目右侧的下载按钮。
6. DASH 页面如果同时显示 `V` 和 `A`，请分别下载视频流与音频流，再在本地合并。

右上角的圆形箭头会重新扫描当前页面，不会刷新整个网页。“清空当前页”会删除当前标签页已经记录的媒体，适合在切换视频或出现旧记录时使用。

## 如何理解下载结果

### 普通视频

MP4、WebM 等完整媒体文件通常可以直接播放，也会包含声音。

### HLS

HLS 会把视频拆成很多小分片，并使用 M3U8 播放列表记录顺序。插件会读取播放列表、下载分片并在本地拼接。

- MPEG-TS 分片通常保存为 `.ts`。
- fMP4 分片通常保存为 `.mp4`。
- 标准 AES-128 加密流可以处理。
- SAMPLE-AES、DRM、不可公开访问的密钥和部分 Byte Range 播放列表暂不支持。

`.ts` 文件可直接使用 VLC、PotPlayer 等播放器打开，也可以用 FFmpeg 无损封装为 MP4：

```bash
ffmpeg -i input.ts -c copy output.mp4
```

### DASH

DASH 经常把画面和声音分成两条独立资源。高画质 B 站和 YouTube 视频很常见这种情况：

- `V` 代表视频流，下载后可能没有声音。
- `A` 代表音频流。
- 两个文件都下载完成后，可以使用 FFmpeg 合并。

```bash
ffmpeg -i video.m4s -i audio.m4s -c copy output.mp4
```

如果浏览器只保存了 `.mp3` 或 `.m4a`，说明当前识别到的是音频流；这不代表视频已经完整下载。

## 设置

在扩展程序详情页打开“扩展程序选项”，可以调整：

- 下载文件名前缀。
- 下载时是否始终弹出保存位置窗口。

文件名会自动移除 Windows 不允许使用的字符。标题过长时，插件会缩短文件名，避免浏览器提示 `Invalid filename`。

## 常见问题

### 页面正在播放视频，插件仍显示 0 个媒体

依次尝试：

1. 先播放视频几秒，再点击右上角重新扫描。
2. 如果刚更新过插件，在 `chrome://extensions/` 中点击一次“重新加载”，随后刷新视频页面。
3. 清空当前页记录后重新播放。
4. 检查该视频是否使用 DRM、Blob、受限密钥或临时签名地址。

### 页面只有一个视频，却出现多个条目

播放器可能同时请求预览片段、多个清晰度、音频流、视频流和备用 CDN。插件会尽量归组，但网站播放器更新后仍可能出现重复项。可以先“清空当前页”，只播放目标视频，然后重新扫描。

### 下载的视频没有声音

该条目大概率是 DASH 视频流。回到插件中下载对应的音频流，再使用上面的 FFmpeg 命令合并。

### 下载到最后提示“无法从网站上提取文件”或“被浏览器取消”

常见原因包括媒体地址过期、站点要求特定请求头、登录状态变化、CDN 拒绝扩展访问，以及浏览器安全策略阻止下载。重新播放并扫描可以获得新的临时地址；如果仍然失败，请记录网站、插件版本和错误提示后提交 Issue。

### 下载结果是 HTML、TXT 或体积很小的 MP4

这通常说明媒体地址已经失效，服务器返回了网页错误信息或跳转页面。请删除该文件，清空当前页记录，然后重新播放视频并扫描。

### YouTube 能显示资源，但无法下载

YouTube 的媒体链接经常包含短时签名，也会动态调整播放器参数。当前版本只使用页面已经公开提供、无需额外解密的地址，因此部分视频无法下载。高画质视频还可能只提供分离的视频流和音频流。

## 隐私与权限

插件会在本地处理以下信息：

- 当前页面地址、标题、作者、封面和分集信息。
- 浏览器已经请求的媒体地址、类型、大小和清晰度信息。
- 下载任务所需的临时分片数据。

这些数据不会上传到开发者服务器。HLS 下载产生的临时本地数据会在任务结束后尽力清理。

扩展需要访问网页和网络请求，才能识别播放器实际加载的资源；需要下载权限，才能把用户主动选择的媒体保存到本地。完整说明见 [隐私政策与权限说明](docs/PRIVACY_POLICY.zh-CN.md)，上架文案见 [Chrome Web Store 资料](docs/CHROME_WEB_STORE_LISTING.md)。

## 开发与打包

```bash
# 静态检查
npm run check

# 构建可加载的 dist 目录
npm run build

# 生成 Chrome Web Store / GitHub Release ZIP
npm run release
```

发布包生成在 `release/` 目录，文件名格式为：

```text
maru-media-sniffer-<version>.zip
```

项目主要目录：

```text
src/background/  网络请求监听、媒体归组与下载管理
src/content/     页面标题、作者、封面及平台信息提取
src/popup/       工具栏弹窗界面
src/options/     文件命名和下载设置
src/shared/      类型识别、命名和通用逻辑
docs/            隐私政策、权限说明和发布检查清单
scripts/         检查、构建和打包脚本
```

## 提交问题

如果遇到识别错误、重复资源或下载失败，请在 GitHub Issues 中尽量提供：

- 插件版本和 Chrome 版本。
- 网站名称及页面类型；公开链接可直接附上。
- 实际看到的媒体数量和插件显示的数量。
- 完整错误提示及截图。
- 从打开页面到复现问题的操作步骤。

请勿提交 Cookie、账号密码、登录令牌、私人页面地址或带有个人凭据的媒体链接。

## 已知限制

- 网站播放器和 CDN 策略变化后，平台适配可能需要更新。
- DASH 视频流与音频流暂不自动合并。
- HLS 的 DRM、SAMPLE-AES、受限密钥和部分 Byte Range 流暂不支持。
- 当前主要面向 Chrome Manifest V3，其他 Chromium 浏览器尚未完成系统验证。
- 插件只保存用户有权使用的公开内容；使用者需要自行遵守网站条款及当地法律。
